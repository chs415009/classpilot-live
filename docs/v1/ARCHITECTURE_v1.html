ClassPilot Agent Architecture

The agent part of ClassPilot Live, as built so far. It takes live class evidence as JSON, decides between continue, reteach, answer and escalate, and writes one trace per decision. Today the input comes from mock JSON files; the front end, backend and data pipeline belong to teammates.
